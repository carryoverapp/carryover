# Carryover

**One memory for all your AIs, kept on your own computer.**

Carryover brings your Claude, ChatGPT, Claude Code, Codex and Antigravity chats into one private memory graph. Compare models side by side, carry a chat from one AI to another, and keep what they've learned about you in one place.

**Website:** https://farazahmadnagrami.github.io/carryover-app/
**Download:** [latest release](https://github.com/FarazAhmadNagrami/carryover-app/releases/latest) (Windows 10 and 11; macOS coming)

This repository holds the website (Vite, React, Tailwind, shadcn/ui, Motion) and the installers. The app's source code is private.

Run the site locally with `pnpm install && pnpm dev`.

## Install

1. Download `Carryover-Windows-x64-setup.exe` from the [latest release](https://github.com/FarazAhmadNagrami/carryover-app/releases/latest).
2. Run it. It installs for your user only, so no admin rights are needed.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. That's normal for new apps that aren't code-signed yet.

## Privacy

There's no account, no server and no tracking. Your chats are stored in a database on your computer. Text only goes online when you choose an online model for a task, and Carryover names the company it goes to before anything is sent. With Ollama it can run fully offline.
